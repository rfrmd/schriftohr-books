# The SchriftOhr Editions

Carefully prepared public-domain reading editions, published by
[RFRMD Word Labs LLC](https://rfrmdwordlabs.com) for
[SchriftOhr](https://schriftohr.com) — and for anyone. Each edition is
a clean text with real chapter structure, set for reading, for
listening, and for discussion in company.

`shelf.json` is the machine-readable shelf; the files live under
`books/`, served via GitHub Pages at
`https://rfrmd.github.io/schriftohr-books/`.

## The shelf

- **The Pilgrim's Progress** — John Bunyan. Both parts, unmodernised,
  the journey's stages as chapters, Scripture-only footnotes, Bunyan's
  own writings as endnotes.
  [Download EPUB](https://rfrmd.github.io/schriftohr-books/books/pilgrims-progress/Bunyan_John-SchriftOhr_Edition-Pilgrims_Progress.epub)
